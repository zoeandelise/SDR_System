### 2. 颜色系统不一致

* NewHomePage: slate-800标题、slate-500副标题、emerald-500主色

* 其他页面: 颜色使用混乱，缺乏统一规范

* NewHomePage: `bg-white/70 backdrop-blur-sm`

* 部分页面grid布局在小屏幕上表现不佳

## 二、优化计划

### Phase 1: 图标统一化 (优先级: 高)

**目标**: 将所有页面的emoji替换为Lucide Icons

**涉及文件**:

1. `SimpleDietLogPage.tsx` - 替换餐次、营养素图标
2. `SimpleFoodDatabasePage.tsx` - 替换分类、搜索图标
3. `SmartRecommendationPage.tsx` - 替换AI、营养素图标
4. `DietHistoryPage.tsx` - 替换历史、推荐图标
5. `SettingsPage.tsx` - 替换设置项图标
6. `HealthGoalPage.tsx` - 替换目标、营养图标

**图标映射表**:

* 🔥热量 → Flame

* 💪蛋白质 → Dumbbell

* 🌾碳水 → Wheat

* 🧈脂肪 → Droplet

* 🍳早餐 → Sun

* 🍱午餐 → Utensils

* 🍲晚餐 → Moon

* 🎯目标 → Target

* 📊统计 → BarChart3

* 🤖AI → Sparkles/Brain

* ⚖️体重 → Scale

* 📈趋势 → TrendingUp

* 👤用户 → User

* ⚙️设置 → Settings

* 🔔通知 → Bell

* 🔒安全 → Shield

### Phase 2: 颜色系统统一

**标准颜色规范**:

* 主标题: `text-slate-800` 或 `bg-gradient-to-r from-gray-900 to-gray-700`

* 副标题: `text-slate-500` 或 `text-gray-500`

* 主强调色: `emerald-500` (绿色系)

* 热量: `orange-500`

* 蛋白质: `blue-500`

* 碳水: `amber-500`

* 脂肪: `purple-500`

### Phase 3: 玻璃态效果统一

**标准样式**:

```css
bg-white/70 backdrop-blur-sm rounded-2xl border border-gray-100/50
```

### Phase 4: 响应式优化

* 确保所有grid在小屏幕上正确堆叠

* 统一使用 `grid-cols-1 lg:grid-cols-2/3` 模式

***

## 三、实施顺序

1. **HealthGoalPage.tsx** - 核心页面，优先优化
2. **SimpleDietLogPage.tsx** - 高频使用页面
3. **SmartRecommendationPage.tsx** - AI功能页面
4. **DietHistoryPage.tsx** - 历史记录页面
5. **SimpleFoodDatabasePage.tsx** - 食物库页面
6. **SettingsPage.tsx** - 设置页面

***

* ✅ 所有页面使用统一的Lucide Icons图标系统

* ✅ 一致的颜色规范和视觉层次

* ✅ 统一的玻璃态设计语言
