### 🔄 4. 数据流集成

#### 请求拦截器
```javascript
api.interceptors.request.use((config) => {
  // 添加认证token
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

#### 响应拦截器
```javascript
api.interceptors.response.use(
  (response) => {
    // 若依框架响应格式处理
    if (response.data.code === 200) {
      return response.data;
    } else {
      throw new Error(response.data.msg);
    }
  },
  (error) => {
    // 统一错误处理
    switch (error.response?.status) {
      case 401: // 未授权
      case 403: // 无权限
      case 404: // 不存在
      case 500: // 服务器错误
    }
  }
);
```

```typescript
useEffect(() => {
  if (searchTerm.trim()) {
    const searchFoods = async () => {
      try {
        const response = await foodApi.searchFoods(searchTerm);
        setFoods(response.data);
      } catch (err) {
        // 降级到本地搜索
        const filtered = getDefaultFoods().filter(food => 
          food.foodName?.toLowerCase().includes(searchTerm.toLowerCase())
        );
        setFoods(filtered);
      }
    };
    const timeoutId = setTimeout(searchFoods, 300);
    return () => clearTimeout(timeoutId);
  }
}, [searchTerm]);
```

## 📈 数据流图

```
用户操作 → React组件 → API服务 → 后端控制器 → 业务服务 → 数据库
   ↓           ↓         ↓         ↓          ↓         ↓
响应数据 ← 状态更新 ← HTTP响应 ← JSON数据 ← 业务逻辑 ← 数据查询
```

### 典型数据流示例：获取仪表板数据
1. **用户访问首页** → `HomePage.tsx`
2. **组件挂载** → `DashboardCards.tsx` `useEffect`
3. **API调用** → `dashboardApi.getDashboardData()`
4. **HTTP请求** → `GET /api/user/diet/dashboard`
5. **后端处理** → `UserDietApiController.getDashboardData()`
6. **数据查询** → `IDietRecordService.selectNutritionSummary*()`
7. **响应返回** → JSON格式营养数据
8. **前端更新** → `setDashboardData(response.data)`
9. **UI渲染** → 营养卡片和图表更新
