# 🚀 健康饮食助手 - 启动指南

## 项目简介

这是一个基于 **React + TailwindCSS + shadcn/ui** 构建的健康饮食类网站用户端首页框架，采用现代化的设计风格，适合健康饮食主题。

## ✨ 特色功能

### 🎨 视觉设计
- **清新配色**：绿色主调配合温暖的黄色和清爽的蓝色
- **卡片式布局**：圆角、阴影、渐变效果
- **响应式设计**：完美适配桌面端和移动端
- **现代动画**：平滑过渡和悬停效果

### 📊 功能模块
- **个人仪表板**：营养摄入统计、健康评分、趋势分析
- **快捷操作**：记录饮食、扫码识别、智能推荐
- **导航系统**：饮食记录、食物库、营养目标、健康报告等
- **实时统计**：侧边栏显示今日营养摄入情况

## 🛠️ 技术栈

- **React 18** + **TypeScript**：现代前端开发
- **TailwindCSS**：实用优先的CSS框架
- **shadcn/ui**：高质量的组件设计系统
- **Lucide React**：精美的图标库
- **CRACO**：Create React App配置覆盖

## 📦 快速启动

### 方法一：使用启动脚本（推荐）

1. **双击运行启动脚本**
   ```
   双击 start.bat 文件
   ```

2. **脚本会自动**：
   - 检查Node.js环境
   - 安装项目依赖（首次运行）
   - 启动开发服务器
   - 在浏览器中打开应用

### 方法二：手动启动

1. **打开命令行**
   ```bash
   # 进入项目目录
   cd sdr-user-frontend
   ```

2. **安装依赖**（首次运行）
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm start
   ```

4. **打开浏览器**
   - 应用将自动在 [http://localhost:3000](http://localhost:3000) 打开
   - 如果没有自动打开，请手动访问该地址

## ⚙️ 自定义配置

### 修改主题色彩
编辑 `tailwind.config.js` 文件：

```javascript
theme: {
  extend: {
    colors: {
      primary: {
        // 自定义主色调
        500: '#您的颜色',
        600: '#您的颜色',
      }
    }
  }
}
```

### 添加新组件
在 `src/components/` 目录下创建新的React组件文件。

### 修改布局
编辑 `src/components/Layout.tsx` 文件来调整整体布局。

## 🔍 故障排除

### 常见问题

1. **Node.js版本问题**
   - 确保安装了Node.js 14或更高版本
   - 下载地址：https://nodejs.org/

2. **依赖安装失败**
   ```bash
   # 清除缓存并重新安装
   npm cache clean --force
   rm -rf node_modules package-lock.json
   npm install
   ```

3. **端口被占用**
   ```bash
   # 使用其他端口启动
   set PORT=3001 && npm start
   ```

4. **页面空白**
   - 检查浏览器控制台是否有错误
   - 确保所有依赖已正确安装

### 获取帮助

如果遇到问题，请：
1. 查看浏览器控制台错误信息
2. 检查终端/命令行的错误输出
3. 参考项目README.md文档
