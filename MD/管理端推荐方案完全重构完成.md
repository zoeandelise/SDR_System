## 🔧 后端对接

### SQL优化
```xml
<select id="selectDietRecommendationList">
  SELECT r.*, u.user_name
  FROM diet_recommendation r
  LEFT JOIN sys_user u ON r.user_id = u.user_id
  <where>
    <!-- 支持用户搜索 -->
    <if test="userName != null">
      and (u.user_name like concat('%', #{userName}, '%') 
           or r.user_id = #{userName})
    </if>
    <!-- 支持方案类型筛选 -->
    <if test="mealType != null">
      and r.meal_type = #{mealType}
    </if>
    <!-- 支持算法类型筛选 -->
    <if test="algorithmType != null">
      and r.algorithm_type = #{algorithmType}
    </if>
    <!-- 支持状态筛选 -->
    <if test="isAccepted != null">
      and r.is_accepted = #{isAccepted}
    </if>
  </where>
  ORDER BY r.recommendation_date DESC
</select>
```
