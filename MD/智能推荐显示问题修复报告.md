## 🔍 问题分析

### 前端工作流程

1. **用户点击"智能推荐"按钮**
   ```javascript
   <el-button type="info" icon="el-icon-magic-stick" @click="getRecommendation">
     智能推荐
   </el-button>
   ```

2. **调用getRecommendation()方法**
   ```javascript
   async getRecommendation() {
     const response = await generateQuickRecommendation();
     if (response.code === 200) {
       this.$modal.msgSuccess('推荐生成成功！');
       const recommendation = response.data;
       if (recommendation.recommendedFoods) {
         this.$message({
           message: `推荐：${recommendation.recommendedFoods}`,
           type: 'success',
           duration: 5000
         });
       }
     }
   }
   ```

3. **API调用**
   ```javascript
   // 调用 POST /diet/dashboard/quick-recommendation
   export function generateQuickRecommendation(userId) {
     return request({
       url: '/diet/dashboard/quick-recommendation',
       method: 'post',
       params: { userId: userId }
     })
   }
   ```

### 问题根源

**后端接口存在两个问题**:

1. **数据库插入失败**
   - 缺少必填字段 `meal_type`
   - 导致SQL异常，接口可能返回错误

2. **返回数据格式问题**
   - 前端期望 `recommendedFoods` 是字符串
   - 原来的代码返回格式不完整
