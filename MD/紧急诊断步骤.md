
打开新的命令行窗口：


```json
{
  "code": 200,
```

## 快速验证方法

### 方法A：添加临时日志

在 `MLDataService.java` 的 `getTrainingProgress` 方法中添加：

```java
public Map<String, Object> getTrainingProgress() {
    Map<String, Object> result = new HashMap<>();
    try {
        List<Map<String, Object>> activeTrainings = getActiveTrainings();
        
        // 临时调试日志
        System.out.println("=== DEBUG: activeTrainings size = " + activeTrainings.size());
        for (Map<String, Object> t : activeTrainings) {
            System.out.println("=== DEBUG: trainingStatus = " + t.get("trainingStatus"));
        }
        
        boolean isTraining = activeTrainings.stream()
            .anyMatch(t -> "training".equals(t.get("trainingStatus")) || 
                          "pending".equals(t.get("trainingStatus")));
        
        System.out.println("=== DEBUG: isTraining = " + isTraining);
        
        result.put("isTraining", isTraining);
        result.put("models", activeTrainings);
```

重启后，在Java后端控制台应该看到：
```
=== DEBUG: activeTrainings size = 2
=== DEBUG: trainingStatus = completed
=== DEBUG: trainingStatus = completed
=== DEBUG: isTraining = false
```

### 方法B：直接查询数据库

```sql
-- 检查训练记录
SELECT 
    training_id,
    model_type,
    training_status,
    progress,
    start_time,
    TIMESTAMPDIFF(SECOND, start_time, NOW()) as seconds_ago
FROM ml_training_history
WHERE start_time >= DATE_SUB(NOW(), INTERVAL 5 MINUTE)
ORDER BY training_id DESC;
```

应该看到：
- `training_status = 'completed'`
- `progress = 100`
- `seconds_ago < 300` (5分钟内)

## 如果API返回isTraining=true

### 可能原因1：Java后端没有重启

**解决：**
1. 完全停止Java后端
2. 等待5秒
3. 重新启动
4. 等待看到启动成功日志

### 可能原因2：代码没有编译

**解决：**
```bash
# IDEA中
Build -> Rebuild Project

# 或者命令行
mvn clean compile
```

### 可能原因3：修改的文件不对

**检查：**
确认修改的是：
```
E:\study\BISHE\SDR_System\SDR_System-diet\src\main\java\com\SDR_System\diet\service\MLDataService.java
```

而不是：
```
E:\study\BISHE\SDR_System\SDR_System-diet\target\classes\...
```

### 可能原因4：Stream API语法错误

**检查Java版本：**
```bash
java -version
```

需要Java 8或更高版本才支持Stream API

**如果Java版本太低，改用传统循环：**
```java
boolean isTraining = false;
for (Map<String, Object> t : activeTrainings) {
    String status = (String) t.get("trainingStatus");
    if ("training".equals(status) || "pending".equals(status)) {
        isTraining = true;
        break;
    }
}
result.put("isTraining", isTraining);
```
