# 用户画像功能修复说明

**问题**：三个画像页面都无数据  
**原因**：API接口调用错误  
**状态**：✅ 已修复

---

## 🔍 问题分析

### 问题页面
```
❌ http://localhost:81/diet/profile（管理端）
❌ http://localhost:3000/profile（用户端）
❌ http://localhost:81/diet/admin/users（用户列表）
```

### 根本原因
```
用户端调用了错误的API：
❌ GET /system/user/health（不存在或权限不足）

应该调用：
✓ GET /diet/health/my（获取当前用户健康数据）
```

---

## ✅ 修复方案

### 用户端画像页面

#### 修复前
```typescript
// 错误的API
axios.get('http://localhost:8080/system/user/health')
```

#### 修复后
```typescript
// 正确的API
axios.get('http://localhost:8080/diet/health/my')

// 正确的数据解析
if (response.data.code === 200 && response.data.data) {
  setHealth(response.data.data);
}
```

---

## 📊 后端可用的健康API

### 1. 获取当前用户健康数据
```
GET /diet/health/my

响应：
{
  "code": 200,
  "data": {
    "userId": 1,
    "height": 175,
    "weight": 70,
    "age": 28,
    "gender": "0",
    "bmi": 22.86,
    "bmr": 1680,
    "dailyCalorieGoal": 2100,
    "dailyProteinGoal": 84,
    ...
  }
}
```

### 2. 保存/更新健康数据
```
POST /diet/health/my

Body: {
  "height": 175,
  "weight": 70,
  ...
}
```

### 3. 计算BMI
```
GET /diet/health/bmi
```

### 4. 获取健康评估
```
GET /diet/health/assessment
```
