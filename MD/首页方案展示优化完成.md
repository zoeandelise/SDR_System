## 🎯 完整用户流程

### 从首页开始的完整流程
```
1. 登录首页
   - 看到闪烁提示（今天无记录时）

2. 点击"🚀 一键规划今日三餐"
   - 按钮变"⏳ 生成中..."

3. 3秒后弹出方案弹窗
   - 在首页直接显示
   - 看到早午晚三餐
   - 看到营养总计

4. 两个选择：
   
   选择A：直接接受
   - 点击"关闭"
   - 方案已保存
   - 继续浏览首页

   选择B：需要调整
   - 点击"查看详细方案并调整 →"
   - 跳转到推荐页面
   - 看到完整的交互界面
   - 可以点👍 👎 🔄
   - 保存方案

符合人类直觉！✓
```
