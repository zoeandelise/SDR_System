## 📊 数据关联

### 表关系
```
sys_user_health（健康目标）
  ├─ user_id → sys_user.user_id
  ├─ daily_calorie_goal（每日热量目标）
  ├─ daily_protein_goal（蛋白质目标）
  ├─ daily_carb_goal（碳水目标）
  └─ daily_fat_goal（脂肪目标）

diet_recommendation（推荐方案）
  ├─ user_id → sys_user.user_id
  ├─ meal_type='9'（全天方案）
  ├─ algorithm_type='ML智能推荐-全天方案'
  ├─ recommended_foods（推荐食物）
  └─ is_accepted='1'（已执行）

通过user_id关联！
```
