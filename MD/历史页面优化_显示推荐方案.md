## 📊 数据来源

### 饮食记录
```
表：diet_record
API：GET /api/user/diet/records
显示：用户实际吃的食物
```

### AI推荐方案
```
表：diet_recommendation  
API：GET /diet/recommendation/list
显示：AI生成的全天方案
```

---

## 🎯 用户体验

### 查看推荐方案
```
1. 访问：http://localhost:3000/diet-history
2. 点击："🤖 AI推荐方案 (2)"
3. 查看保存的2个全天方案
4. 看到完整的早午晚三餐食物
```

### 查看饮食记录
```
1. 点击："📝 饮食记录"
2. 查看实际吃的食物记录
3. 按日期分组
```
