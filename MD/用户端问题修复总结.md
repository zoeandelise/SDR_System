## 🔧 常见问题解决

### 问题A：登录返回401

**可能原因**：
1. 用户名或密码错误
2. 验证码未启用但代码要求验证码

**解决**：
```sql
-- 禁用验证码
UPDATE sys_config 
SET param_value = 'false' 
WHERE param_key = 'sys.account.captchaEnabled';
```

---

### 问题B：CORS错误

**症状**：
```
Access to XMLHttpRequest has been blocked by CORS policy
```

**解决**：
1. 确认后端已重启（加载CORS配置）
2. 检查CorsConfig.java是否包含localhost:3000

---

### 问题C：代理不工作

**症状**：
```
GET http://localhost:3000/api/xxx 404
```

**解决**：
1. 重启React开发服务器
2. 检查craco.config.js中的proxy配置
