# 管理端用户列显示修复

**问题**：管理端饮食记录看不到用户信息  
**修复**：添加用户列  
**状态**：✅ 已完成

---

## ✅ 修复内容

### 新增用户列
```vue
<el-table-column label="用户" prop="userName" width="120">
  <template slot-scope="scope">
    <el-tag type="info" size="small">
      {{ scope.row.userName || 'ID:' + scope.row.userId }}
    </el-tag>
  </template>
</el-table-column>
```

### 显示效果
```
表格列顺序：
[选择] [用户] [记录日期] [餐次] [热量] [蛋白质] [脂肪] [碳水] ...

用户列显示：
- 如果有userName：显示用户名（如：admin）
- 如果无userName：显示ID（如：ID:101）

用蓝色标签显示
```

## 📊 数据来源

### 后端已返回userName
```java
// DietRecordMapper.xml
SELECT 
  r.*, 
  u.user_name  ← 已join查询
FROM diet_record r
LEFT JOIN sys_user u ON r.user_id = u.user_id
```

**后端数据正常！** ✓
