# TypeScript编译错误修复

**错误**：TS2802 Set展开运算符问题  
**修复时间**：2025-10-11

---

## 🔍 错误分析

### 原错误代码
```typescript
setAddedFoods(new Set([...addedFoods, item.food_id]));
```

### 错误原因
```
TypeScript编译器在当前target配置下，
不支持Set类型的展开运算符（...操作符）
```

---

## ✅ 修复方案

### 修复后代码
```typescript
const newAdded = new Set(addedFoods);
newAdded.add(item.food_id);
setAddedFoods(newAdded);
```

### 原理
```
不使用展开运算符，直接：
1. 创建新Set（从旧Set复制）
2. 添加新元素
3. 更新状态
```
