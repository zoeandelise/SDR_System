## 后端API改造

**文件**：`SDR_System-diet/src/main/java/com/SDR_System/diet/controller/DietMLController.java`

在 `getMLAnalytics` 方法中：

```java
@GetMapping("/analytics")
public AjaxResult getRecommendationAnalytics() {
    try {
        Map<String, Object> analytics = new HashMap<>();
        
        // 从真实数据库统计
        String sql = "SELECT " +
            "COUNT(*) as total_recommendations, " +
            "COUNT(CASE WHEN is_accepted='1' THEN 1 END) * 100.0 / COUNT(*) as acceptance_rate, " +
            "AVG(score) as avg_score, " +
            "COUNT(DISTINCT user_id) as active_users " +
            "FROM diet_recommendation WHERE is_accepted IS NOT NULL";
        
        Map<String, Object> stats = jdbcTemplate.queryForMap(sql);
        
        analytics.put("total_recommendations", stats.get("total_recommendations"));
        analytics.put("acceptance_rate", stats.get("acceptance_rate"));
        analytics.put("avg_score", stats.get("avg_score"));
        analytics.put("active_users", stats.get("active_users"));
        
        return AjaxResult.success(analytics);
        
    } catch (Exception e) {
        logger.error("获取推荐分析失败", e);
        return AjaxResult.error("获取失败: " + e.getMessage());
    }
}
```
