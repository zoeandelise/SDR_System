## ✅ 已完成修改

### 修改1：MLDataMapper.xml（数据源替换）

**文件路径**：`SDR_System-diet/src/main/resources/mapper/diet/MLDataMapper.xml`

#### 修改点A：aggregateRecommendationStats 方法

**修改前**：
```sql
FROM ml_recommendation_stats  -- 假数据表
```

**修改后**：
```sql
FROM diet_recommendation  -- 真实推荐记录表
```

**数据对比**：
| 字段 | 假数据源 | 真实数据源 | 计算逻辑 |
|------|----------|------------|----------|
| totalRecommendations | ml_recommendation_stats.total_recommendations | COUNT(*) FROM diet_recommendation | 直接统计记录数 |
| acceptanceRate | ml_recommendation_stats.acceptance_rate | COUNT(is_accepted='1')/COUNT(is_accepted IS NOT NULL) | 基于真实反馈计算 |
| avgScore | ml_recommendation_stats.avg_score | AVG(score) | 用户评分平均值 |
| activeUsers | ml_recommendation_stats.active_users | COUNT(DISTINCT user_id) | 去重用户数 |

#### 修改点B：aggregateStatsByAlgorithm 方法

**修改前**：
```sql
FROM ml_recommendation_stats  -- 聚合假数据
GROUP BY algorithm_type
```

**修改后**：
```sql
FROM diet_recommendation  -- 从真实记录统计
GROUP BY COALESCE(algorithm_type, 'rule_based')
```

**算法统计逻辑**：
```sql
-- 准确率 = 接受率
accuracy = (接受数 / 有反馈数) × 100

-- 响应时间 = 平均响应时间（ms）
responseTime = AVG(response_time)

-- 推荐次数
recommendations = COUNT(*)

-- 使用占比
usage = (该算法推荐数 / 总推荐数) × 100
```
