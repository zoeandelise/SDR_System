1. 停止前端服务（关闭运行 npm 的窗口）

## ⚠️ 常见问题

### Q1: 重新登录后还是看不到菜单？

**解决方案**:
1. 确认使用的是管理员账号（admin）
2. 检查浏览器控制台是否有错误
3. 清除浏览器所有缓存
4. 尝试使用无痕模式打开

### Q2: 菜单显示但点击没有反应？

**可能原因**:
- 前端页面组件还未开发
- 路由配置问题

**解决方案**:
检查 `SDR_System-ui/src/views/diet/` 目录下是否有对应的页面组件。

### Q3: 提示"没有权限"？

**解决方案**:
确认当前登录用户的角色是否有相应权限。运行以下SQL检查：
```sql
SELECT r.role_name, COUNT(rm.menu_id) as menu_count
FROM sys_user_role ur
JOIN sys_role r ON ur.role_id = r.role_id
JOIN sys_role_menu rm ON r.role_id = rm.role_id
WHERE ur.user_id = 1 AND rm.menu_id BETWEEN 2000 AND 2120
GROUP BY r.role_name;
```
