## 📊 数据验证SQL

如果想手动验证数据，在MySQL中执行：

```sql
-- 查看模型信息
SELECT model_name, model_type, is_loaded FROM ml_model_info;

-- 查看推荐统计
SELECT stat_date, algorithm_type, total_recommendations, acceptance_rate 
FROM ml_recommendation_stats 
ORDER BY stat_date DESC 
LIMIT 10;

-- 查看服务状态
SELECT service_status, check_time 
FROM ml_service_status 
ORDER BY check_time DESC 
LIMIT 1;
```

## ❗ 重要提示

### 如果显示全0
- **原因**: 数据库脚本未执行
- **解决**: 回到第1步，重新导入SQL脚本

### 如果无法启动训练
- **原因**: ml_model_info表无数据
- **解决**: 检查数据库，重新执行init_ml_data.sql

### 如果页面报404
- **原因**: 后端未启动或端口冲突
- **解决**: 检查后端日志，确认服务已启动
