## 🎯 交互效果

### 点击喜欢
```
1. 食物标签变绿色边框
2. 显示👍图标
3. 从不喜欢中移除
4. 底部统计+1
```

### 点击不喜欢
```
1. 食物标签变红色边框
2. 显示👎图标
3. 从喜欢中移除
4. 底部统计+1
```

### 点击换一个
```
1. 调用推荐API
2. 获取新食物
3. 实时替换
4. Toast提示"✨ 已更换为 XXX"
```
