# 前端显示90%问题的根本原因

## 问题确认

✅ **ML服务工作正常**
- 训练确实完成了
- 进度确实更新到100%
- 数据库状态确实更新为completed

❌ **前端显示停在90%**
- 前端轮询progress API
- Java后端查询数据库
- 但是查询条件有问题

## 根本原因

### Java后端查询逻辑

```java
SELECT ... FROM ml_training_history 
WHERE training_status IN ('pending', 'training')  ← 问题在这里！
ORDER BY start_time DESC
```

### 问题分析

1. **训练进行中**：status = 'training'
   - 查询能找到记录 ✅
   - 前端显示进度：5% → 10% → ... → 90%

2. **训练完成**：status = 'completed'
   - 查询找不到记录 ❌（因为WHERE条件只包含pending和training）
   - Java后端返回空列表
   - 前端保持最后一次轮询的状态（90%）

3. **前端停止轮询的条件**：
   ```javascript
   // management.vue 第609-643行
   if (progressData.isTraining === false || this.allModelsCompleted) {
       clearInterval(this.pollingTimer)
   }
   ```
   - `isTraining` 由Java后端返回
   - 当查询结果为空时，Java后端可能返回 `isTraining: true`
   - 所以前端一直轮询，一直显示90%

## 解决方案

### 方案1：修改Java后端查询逻辑（推荐）

在 `MLTrainingMapper.xml` 或对应的Mapper中，修改查询条件：

```xml
<!-- 原查询 -->
<select id="selectActiveTrainings">
    SELECT ... FROM ml_training_history 
    WHERE training_status IN ('pending', 'training')
    ORDER BY start_time DESC
</select>

<!-- 修改后 -->
<select id="selectActiveTrainings">
    SELECT ... FROM ml_training_history 
    WHERE training_status IN ('pending', 'training', 'completed', 'failed')
    AND start_time >= DATE_SUB(NOW(), INTERVAL 5 MINUTE)
    ORDER BY start_time DESC
</select>
```

**说明：**
- 包含所有状态（pending, training, completed, failed）
- 只返回最近5分钟的记录
- 这样训练完成后的短时间内，前端仍能获取到completed状态

### 方案2：修改Java后端返回逻辑

在 `MLDataService.java` 或类似的服务类中：

```java
public Map<String, Object> getActiveTrainings() {
    List<TrainingHistory> trainings = mapper.selectActiveTrainings();
    
    // 如果没有活动训练，检查是否有最近完成的
    if (trainings.isEmpty()) {
        trainings = mapper.selectRecentCompletedTrainings(5); // 最近5分钟
    }
    
    boolean isTraining = trainings.stream()
        .anyMatch(t -> "training".equals(t.getTrainingStatus()));
    
    Map<String, Object> result = new HashMap<>();
    result.put("isTraining", isTraining);
    result.put("models", trainings);
    result.put("overallProgress", calculateOverallProgress(trainings));
    result.put("totalModels", trainings.size());
    
    return result;
}
```

### 方案3：修改前端轮询逻辑（临时方案）

在 `management.vue` 中：

```javascript
async updateTrainingProgress() {
    try {
        const response = await getTrainingProgress()
        const progressData = response.data
        
        // 如果没有训练任务，检查数据库中最近的训练记录
        if (!progressData.models || progressData.models.length === 0) {
            // 可能刚完成，再查询一次最近的训练历史
            const historyResponse = await getTrainingHistory({ limit: 2 })
            if (historyResponse.data && historyResponse.data.length > 0) {
                // 使用历史记录更新显示
                this.trainingModels = historyResponse.data.map(h => ({
                    modelType: h.modelType,
                    status: h.trainingStatus,
                    progress: h.progress,
                    currentStep: h.currentStep
                }))
            }
        } else {
            this.trainingModels = progressData.models
        }
        
        // 检查是否所有模型都完成
        if (this.allModelsCompleted) {
            clearInterval(this.pollingTimer)
            this.$message.success('所有模型训练完成！')
        }
    } catch (error) {
        console.error('获取训练进度失败:', error)
    }
}
```
