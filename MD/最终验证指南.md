## 🔍 深入说明

### 为什么会"模拟训练"？

查看日志：
```
ERROR: 404 Not Found: "{"error": "Not found"}"
INFO: ML服务离线，使用模拟训练
```

**原因**：
1. 后端调用ML服务的 `/api/model/train` 接口
2. ML服务返回404（接口不存在或路径错误）
3. 系统自动降级到模拟模式

**ML服务当前提供的接口**：
```
GET  /health - 健康检查 ✓
GET  /api/model/status - 模型状态 ✓
GET  /api/training/progress - 训练进度 ✓
POST /api/model/train - 开始训练 ⚠️ 可能路径不同
```
