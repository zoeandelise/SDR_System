## 临时解决方案

如果实在无法修复Java后端的轮询，可以修改ML服务，让它在训练完成后立即清空training_tasks：

在 `main_service.py` 中，训练完成后添加：

```python
# 训练完成后，延迟5秒后清空任务
import time
time.sleep(5)
if task_key in training_tasks:
    del training_tasks[task_key]
```

这样Java后端查询时会得到空结果，虽然不优雅但能解决问题。
