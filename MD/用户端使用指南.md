## 🛠️ 常见问题排查

### 问题1：登录后立即跳转回登录页

**原因**：Token未正确保存或getUserInfo失败

**排查**：
1. 检查Cookies中是否有Admin-Token
2. 检查Console是否有错误
3. 检查Network面板getInfo请求是否成功

**解决**：
```typescript
// 确认authService.ts中的setToken实现
setToken(response.token);  // 应该调用Cookies.set
```

---

### 问题2：API请求返回401

**原因**：Token未添加到请求头

**排查**：
1. 检查Network面板，请求头是否有Authorization
2. 检查Console是否有拦截器错误

**解决**：
```typescript
// 确认api.ts中的请求拦截器
const token = localStorage.getItem('token') || sessionStorage.getItem('token');
// 应该改为从Cookies读取
const token = Cookies.get('Admin-Token');
```

---

### 问题3：网络连接失败

**症状**：
```
Network Error
ERR_CONNECTION_REFUSED
```

**原因**：后端服务未启动

**解决**：
```batch
# 启动后端
start_backend.bat

# 检查端口
netstat -ano | findstr ":8080"
```

---

### 问题4：CORS错误

**症状**：
```
Access to XMLHttpRequest blocked by CORS policy
```

**原因**：后端CORS配置未生效

**解决**：
1. 确认后端已重启
2. 检查CorsConfig.java包含localhost:3000
3. 清除浏览器缓存重试
