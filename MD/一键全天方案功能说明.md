## ✨ 功能说明

### 用户操作
```
1. 访问：http://localhost:3000/smart-recommendation
2. 点击右上角："✨ 一键生成全天方案"
```

## 🤖 后端实现

### 生成逻辑
```java
// DailyMealPlanService.java

1. 生成早餐推荐（3种食物）
   CALL generate_diverse_recommendation_simple(userId, '0', 3)

2. 生成午餐推荐（5种食物）
   CALL generate_diverse_recommendation_simple(userId, '1', 5)

3. 生成晚餐推荐（5种食物）
   CALL generate_diverse_recommendation_simple(userId, '2', 5)

4. 计算全天营养总计
   总热量 = 早餐 + 午餐 + 晚餐
   总蛋白质 = ...
   ...

5. 保存到diet_recommendation表
   记录被推荐人、推荐内容、生成时间
```
