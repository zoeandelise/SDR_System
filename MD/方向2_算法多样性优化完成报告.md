### 优化1：近期推荐过滤 ⭐

**函数名**：`get_recent_food_penalty(user_id, food_name, days_back)`

**功能**：查询用户近7天推荐记录，对重复食物降低权重

**惩罚机制**：
| 近7天推荐次数 | 惩罚系数 | 说明 |
|--------------|----------|------|
| 0次 | 1.0 | 无惩罚，优先推荐 |
| 1次 | 0.7 | 轻度惩罚，降权30% |
| 2次 | 0.5 | 中度惩罚，降权50% |
| 3次及以上 | 0.3 | 重度惩罚，降权70% |

**实现逻辑**：
```sql
-- 查询近7天内该食物被推荐次数
SELECT COUNT(*)
FROM diet_recommendation
WHERE user_id = p_user_id
  AND recommended_foods LIKE CONCAT('%', p_food_name, '%')
  AND recommendation_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY);

-- 计算惩罚系数并应用到评分
final_score = nutrition_score × penalty_factor
```

**预期效果**：
- 近期推荐过的"鸡胸肉+糙米饭+西兰花"组合权重下降
- 新食材获得推荐机会增加
- 用户感受到推荐多样性提升

### 优化2：分类多样性保障 ⭐

**函数名**：`calculate_category_diversity_bonus(category_name)`

**功能**：根据食物分类给予额外加分，确保推荐包含多类食材

**分类奖励分**：
| 食物分类 | 奖励分 | 重要性 | 说明 |
|----------|--------|--------|------|
| 谷物/主食类 | +10分 | 最高 | 主食必不可少 |
| 肉类/蛋类/豆类 | +8分 | 高 | 蛋白质来源 |
| 蔬菜类 | +6分 | 中高 | 维生素和纤维 |
| 水果类 | +5分 | 中 | 营养补充 |
| 其他类 | +3分 | 低 | 多样性补充 |

**实现策略（新存储过程）**：
```sql
CREATE PROCEDURE generate_balanced_recommendation(...)
-- 策略：
-- 1. 从谷物类选2个（主食基础）
-- 2. 从肉类/豆类选2个（蛋白质保证）
-- 3. 从蔬菜类选3个（维生素和纤维）
-- 4. 从其他类补充剩余
-- 5. 按分类优先级+评分排序

-- 确保每餐至少包含2-3个不同分类
```

**预期效果**：
- 每餐推荐包含"主食+蛋白质+蔬菜"至少2类 ✓
- 避免单一品类推荐（如全是蔬菜）
- 营养更均衡，符合膳食指南

### 优化3：随机因子控制 ⭐

**实现方式**：在营养匹配度≥70分的食物中加入0-10分的随机分

**随机逻辑**：
```sql
random_factor = FLOOR(RAND() * 10)

final_score = (
    (nutrition_score × recent_penalty + diversity_bonus + random_factor) × 0.70
    + history_score × 0.30
)
```

**控制机制**：
- ✅ 只有营养匹配度≥60分的食物才会进入候选池
- ✅ 随机因子最多10分，不会显著影响营养合理性
- ✅ 每次调用结果略有不同，增加新鲜感

**预期效果**：
- 同分食物不再固定排序
- 每次推荐结果有30%概率不同
- 用户体验更佳，减少"总是推荐同样东西"的感觉

### 验证1：推荐重复率测试

```sql
-- 查询用户101的推荐重复率
SELECT 
    COUNT(*) AS '总推荐次数',
    COUNT(DISTINCT recommended_foods) AS '唯一推荐组合',
    ROUND((1 - COUNT(DISTINCT recommended_foods) * 1.0 / COUNT(*)) * 100, 2) AS '重复率(%)',
    CASE 
        WHEN (1 - COUNT(DISTINCT recommended_foods) * 1.0 / COUNT(*)) * 100 <= 10 THEN '✓ 优秀'
        ELSE '需继续优化'
    END AS '评价'
FROM diet_recommendation
WHERE user_id = 101;
```

**优化后预期**：重复率从80%下降到≤10%
