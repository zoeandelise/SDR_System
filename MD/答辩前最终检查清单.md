### Q2：推荐算法的创新点在哪里？

**回答**：
"主要有三点创新：
1. 营养优先于口味：营养匹配权重70%，远高于通用推荐的20-30%
2. 基于生理指标：使用BMI、BMR、慢性病等健康指标，而非简单行为数据
3. 硬性健康约束：过敏原和慢性病禁忌是强制性的，不能妥协"

---

### Q3：如何保证推荐的营养合理性？

**回答**：
"系统基于《中国居民膳食指南2024》设计，蛋白质推荐1.2-1.5g/kg体重，
碳水占总热量50-65%，脂肪占20-30%。餐次分配为早30%、午40%、晚30%，
符合营养学原则。每个推荐都经过四维营养素（热量、蛋白质、碳水、脂肪）
的匹配度评分。"

### Q4：训练是模拟的吗？

## 📊 准备的数据查询（现场演示用）

### 查询1：用户健康数据
```sql
SELECT user_id, age, gender, bmi, bmr, diseases, diet_preferences
FROM sys_user_health WHERE user_id=101;
```

### 查询2：食物营养数据
```sql
SELECT food_name, calories, protein, gi_value, sodium_per_100g, 
       purine_per_100g, data_source
FROM diet_food_nutrition n
INNER JOIN diet_food_info f ON n.food_id=f.food_id
WHERE f.food_name IN ('鸡胸肉','糙米饭','西兰花')
ORDER BY f.food_name;
```

### 查询3：推荐记录统计
```sql
SELECT 
    COUNT(*) AS total,
    COUNT(CASE WHEN is_accepted='1' THEN 1 END) AS accepted,
    ROUND(AVG(score),2) AS avg_score
FROM diet_recommendation;
```
