## ⚠️ 发现的问题

### 问题1：MongoDB认证失败

**症状**：删除饮食记录时报错

**根本原因**：
```yaml
# application.yml中的MongoDB配置
mongodb:
  username: root
  password: 1234  # 密码可能不正确
```

**影响范围**：
- 删除功能失败
- 不影响查看和添加（使用MySQL）

**快速解决**（3选1）：

#### 方案A：修复MongoDB密码
```yaml
spring:
  data:
    mongodb:
      password: <正确的密码>
```

#### 方案B：禁用MongoDB（推荐）⭐
```yaml
spring:
  data:
    mongodb:
      # 注释掉所有MongoDB配置
```

修改删除逻辑只使用MySQL：
```java
// UserDietApiController.java
@DeleteMapping("/records/{recordId}")
public AjaxResult deleteRecord(@PathVariable Long recordId) {
    // 只删除MySQL记录，不操作MongoDB
    return toAjax(dietRecordService.deleteDietRecordByRecordIds(...));
}
```

#### 方案C：启动MongoDB并设置正确密码
```batch
# MongoDB Shell
use admin
db.createUser({user:"root", pwd:"1234", roles:["root"]})
```

**推荐**：使用方案B，禁用MongoDB，简化系统
