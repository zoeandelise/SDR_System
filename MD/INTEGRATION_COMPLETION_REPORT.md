## 🔧 技术实现亮点

### 1. 前端技术栈
- **用户端**: React 18 + TypeScript + Tailwind CSS
- **管理端**: Vue 2 + Element UI + ECharts
- **状态管理**: Redux Toolkit (React) / Vuex (Vue)
- **HTTP客户端**: Axios with 拦截器和重试机制

### 2. 后端技术栈
- **框架**: Spring Boot 2.7 + 若依框架
- **安全**: Spring Security + JWT
- **数据库**: MySQL + MongoDB + Neo4j
- **缓存**: Redis (可选)
- **文档**: Swagger/OpenAPI 3.0

### 3. AI/ML技术栈
- **框架**: Python FastAPI + PyTorch
- **算法**: 协同过滤 + 内容推荐 + 深度学习
- **数据处理**: Pandas + NumPy + Scikit-learn
- **模型管理**: 模型版本控制和在线更新

## 🚀 快速启动指南

### 方式一：一键启动（推荐）
```bash
# Windows系统
./start_all_services.bat

# 系统会自动启动：
# - 后端服务 (8080端口)
# - ML服务 (8001端口)  
# - 管理员前端 (81端口)
# - 用户端前端 (3000端口)
```

### 方式二：手动启动
```bash
# 1. 启动后端服务
cd SDR_System
java -jar SDR_System-admin.jar

# 2. 启动ML服务
cd SDR_System-ml
python start_ml_service.py

# 3. 启动管理员前端
cd SDR_System-ui
npm run dev

# 4. 启动用户端前端
cd sdr-user-frontend
npm start
```

### 方式三：集成测试
```bash
# 运行系统集成测试
python test_system_integration.py
```
