## 📋 项目概述

### 核心功能
基于机器学习算法的智能饮食推荐系统，运用营养匹配算法，结合用户BMI、BMR、健康状况，提供个性化饮食推荐。

### 技术栈
- **前端**：Vue.js（管理端）+ React（用户端）
- **后端**：Spring Boot + MyBatis
- **算法**：SQL + Python ML
- **数据库**：MySQL + MongoDB

### 数据规模
- 160个用户健康数据
- 55种食物营养数据
- 68条真实推荐记录
- 331条饮食记录

### 功能特性

#### 1. ML算法展示
- 算法类型：营养匹配算法 V1.0
- 匹配维度：热量·蛋白质·碳水·脂肪（4维）
- 权重分配：营养70% + 偏好30%

#### 2. 推荐功能
- 餐次选择（早午晚加餐）
- 个性化营养目标计算
- 10种智能推荐食物
- 匹配度评分（0-100分）
- AI推荐理由生成

#### 3. 用户交互
- **➕ 加入菜单** - 一键添加到饮食记录

- **Toast反馈** - 即时操作提示
