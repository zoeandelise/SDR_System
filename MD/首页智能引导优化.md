## 🎯 优化理念

### 人类行为逻辑分析

#### 场景1：新用户或今天刚开始
```
用户心理：
- 今天还没吃什么
- 不知道该吃什么
- 希望有人帮忙规划

系统应该：
→ 主动提示："今天还没有饮食计划？"
→ 提供快捷操作："一键规划今日三餐"
→ 降低操作门槛
```

#### 场景2：已有记录的用户
```
用户心理：
- 今天已经有计划了
- 想查看营养摄入
- 想记录更多食物

系统应该：
→ 显示今日数据
→ 提供记录入口
→ 不打扰用户
```

## ✅ 实现方案

### 1. 智能判断显示
```typescript
// 检查今天是否有记录
if (data?.todayRecords?.length === 0) {
  // 显示快速开始提示
  setShowQuickStart(true);
} else {
  // 不显示，避免打扰
  setShowQuickStart(false);
}
```

### 2. 醒目的快速开始卡片
```
位置：ML横幅正下方
颜色：橙红粉渐变（温暖，行动号召）
动画：animate-pulse（闪烁，吸引注意）
图标：✨（魔法，快速）

文案：
  标题："今天还没有饮食计划？"
  说明："AI可以为您智能规划今日三餐"
  按钮："🚀 一键规划今日三餐"
```

### 3. 一键操作流程
```
用户点击"一键规划" →
  1. 按钮变"⏳ 生成中..."
  2. 调用API生成方案
  3. 自动跳转到智能推荐页面
  4. 显示完整方案弹窗
  5. 用户可调整和保存
```
