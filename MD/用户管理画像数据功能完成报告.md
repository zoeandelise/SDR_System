## 📝 数据库表结构要求

### diet_goal（健康目标表）
```sql
CREATE TABLE `diet_goal` (
  `goal_id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '目标ID',
  `user_id` bigint(20) NOT NULL COMMENT '用户ID',
  `goal_name` varchar(100) NOT NULL COMMENT '目标名称',
  `goal_type` varchar(10) NOT NULL COMMENT '目标类型（0减重1增重2维持3增肌4减脂5改善血糖6改善血压）',
  `target_value` decimal(10,2) NOT NULL COMMENT '目标值',
  `current_value` decimal(10,2) DEFAULT NULL COMMENT '当前值',
  `unit` varchar(20) NOT NULL COMMENT '单位',
  `status` varchar(10) DEFAULT '0' COMMENT '状态（0进行中1已完成2已暂停3已取消）',
  `start_date` date NOT NULL COMMENT '开始日期',
  `target_date` date NOT NULL COMMENT '目标日期',
  `description` varchar(500) DEFAULT NULL COMMENT '描述',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`goal_id`),
  KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='健康目标表';
```

## 🔧 技术实现要点

### 1. 字段命名转换
所有SQL查询使用驼峰命名别名：
```java
sqlBuilder.append("SELECT ")
    .append("user_id as userId, ")
    .append("user_name as userName, ")
    .append("nick_name as nickName, ")
    // ...
```

### 2. 分页实现
使用MySQL LIMIT + OFFSET：
```java
int offset = (pageNum - 1) * pageSize;
sqlBuilder.append("LIMIT ?, ?");
params.add(offset);
params.add(pageSize);
```

### 3. 日期过滤
支持开始日期和结束日期筛选：
```java
if (startDate != null && !startDate.isEmpty()) {
    sqlBuilder.append("AND record_date >= ? ");
    params.add(startDate);
}
if (endDate != null && !endDate.isEmpty()) {
    sqlBuilder.append("AND record_date <= ? ");
    params.add(endDate);
}
```

### 4. 统计计算
使用SQL聚合函数：
```sql
COUNT(DISTINCT dr.record_id) as recentRecordsCount
COALESCE(ROUND(AVG(dr.total_calories), 2), 0) as avgCalories
```
