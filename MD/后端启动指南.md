# SDR_System 后端启动指南

## 📋 问题修复总结

### 遇到的问题
```
APPLICATION FAILED TO START
Failed to configure a DataSource: 'url' attribute is not specified
```

### 根本原因
1. **数据库未初始化** - `smart_diet_dev` 数据库不存在
2. **配置文件问题** - Spring Boot 自动配置无法找到顶层数据源配置
3. **编译缓存问题** - 类文件未正确编译导致 `ClassNotFoundException`

### 解决方案
✅ **已修复**
1. 创建数据库初始化脚本
2. 修改 `application-druid.yml`，添加顶层数据源配置
3. 清理并重新编译项目

## 📝 重要脚本说明

### 1. init_database.bat
**功能**: 初始化数据库
- 创建 `smart_diet_dev` 数据库
- 导入基础表结构 (`ry_20250522.sql`)
- 导入饮食系统数据 (`diet_system.sql`)

**使用场景**: 首次部署或数据库损坏时

### 2. manage_backend.bat
**功能**: 后端服务管理工具（推荐使用）
- 启动/停止/重启服务
- 查看服务状态
- 测试 API
- 查看日志

### 3. start_backend.bat
**功能**: 快速启动后端服务
- 自动检查 MySQL 和数据库
- 如果数据库不存在则自动初始化
- 启动 Spring Boot 应用

### 4. check_config.bat
**功能**: 配置检查诊断工具
- 检查 MySQL 服务
- 检查数据库连接
- 检查配置文件
- 检查端口占用

### 5. test_backend.bat
**功能**: 测试后端服务
- 检查端口监听
- 测试 API 响应
- 显示访问地址

## ❗ 常见问题

### 1. 端口 8080 已被占用
```batch
# 查看占用进程
netstat -ano | findstr :8080

# 停止进程
taskkill /F /PID <进程ID>
```

### 2. MySQL 连接失败
```batch
# 检查 MySQL 服务
net start | findstr -i mysql

# 启动 MySQL 服务
net start MySQL80
```

### 3. 数据库不存在
```batch
# 运行初始化脚本
init_database.bat
```

### 4. 编译错误
```batch
# 清理并重新编译
mvn clean compile "-Dmaven.test.skip=true"
```

### 5. 类找不到 (ClassNotFoundException)
```batch
# 清理所有编译文件
mvn clean

# 重新编译
mvn compile "-Dmaven.test.skip=true"
```

## 📊 启动流程

```

   ↓

3. 清理编译缓存 (如需要)
   ↓
4. 编译项目
   ↓
5. 启动 Spring Boot
   ↓
6. 初始化 Druid 数据源
   ↓
7. 连接 MySQL
   ↓
8. 连接 MongoDB
   ↓
9. 启动 Tomcat
   ↓
10. 应用启动完成 ✓
```
