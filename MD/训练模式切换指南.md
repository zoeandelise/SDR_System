# 训练模式切换指南

## 当前训练模式说明

系统设计了**双训练模式**，可以灵活切换：

### 🎭 模式1：模拟训练（默认）⭐ 推荐用于演示

**配置**：`ml.training.simulate-mode: true`

**特点**：
- ✅ 训练速度快（10-15秒完成）
- ✅ 不依赖ML Python服务
- ✅ 训练记录真实（写入数据库）
- ✅ 训练进度真实（可实时查看）
- ⚠️ 训练过程模拟（无实际模型训练）

**适用场景**：
- 功能演示
- 毕业设计答辩
- 快速验证流程

**日志标识**：
```
INFO: ML服务离线，使用模拟训练: collaborative_filtering
INFO: 训练进度: collaborative_filtering - 85% - 模型保存...
```

---

### 🔬 模式2：真实训练

**配置**：`ml.training.simulate-mode: false`

**特点**：
- ✅ 真实的机器学习训练
- ✅ 生成真实模型文件
- ✅ 训练时间真实（可能较长）
- ⚠️ 需要ML Python服务支持
- ⚠️ 需要足够的训练数据

**适用场景**：
- 生产环境
- 真实模型需求
- 算法研究

**前提条件**：
1. ML Python服务运行
2. ML服务实现了真实训练逻辑
3. 有足够的训练数据

---

## 🔧 如何切换训练模式

### 方法1：修改配置文件（永久生效）⭐ 推荐

**文件**：`SDR_System-admin/src/main/resources/application.yml`

```yaml
ml:
  training:
    # 改为false启用真实训练
    simulate-mode: true   # true=模拟, false=真实
    simulate-duration: 15  # 模拟训练时长（秒）
```

**修改步骤**：
1. 打开 `application.yml`
2. 找到 `ml.training.simulate-mode`
3. 修改为 `false`（真实训练）或 `true`（模拟训练）
4. 保存文件
5. 重启后端服务

## 💡 推荐配置

### 对于毕业设计

**推荐使用模拟训练**：
```yaml
ml:
  training:
    simulate-mode: true  # 模拟模式
    simulate-duration: 15
```

**理由**：
1. ✅ 演示流畅（15秒完成）
2. ✅ 不需要额外配置ML服务
3. ✅ 训练记录完整真实
4. ✅ 可以多次演示

**答辩时说明**：
"系统设计了智能降级机制：
- 生产环境：调用ML服务进行真实训练
- 演示环境：使用模拟训练展示功能流程
- 两种模式都会生成真实的训练记录"

---

### 对于生产环境

**配置为真实训练**：
```yaml
ml:
  service:
    enabled: true
    url: http://localhost:8001
  training:
    simulate-mode: false  # 真实模式
```

**前提**：
1. ML Python服务必须运行
2. ML服务实现真实训练逻辑
3. 有足够的训练数据
