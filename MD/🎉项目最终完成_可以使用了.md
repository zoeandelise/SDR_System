## 🎯 核心功能完整演示流程

### 完整使用流程（5分钟）

#### 1. 登录
```
http://localhost:3000/login
账号：admin / admin123
```

#### 2. 查看首页
```
- ML横幅（醒目）
- 今日营养（0或真实数据）
```

#### 3. 生成全天方案
```
1. 点击"✨ 一键生成全天饮食方案"（大按钮）
2. 等待3秒
3. 查看漂亮弹窗（横向3列）
4. 鼠标悬停在食物上
5. 点击👍标记喜欢
6. 点击👎标记不喜欢
7. 点击🔄更换食物
8. 查看底部偏好统计
9. 点击"✅ 确认保存方案"
10. Toast提示"✅ 方案已保存"
```

#### 4. 查看保存的方案
```
方式A：自动跳转到历史记录页
方式B：手动访问 /diet-history

1. 点击"🤖 AI推荐方案"Tab
2. 查看保存的全天方案
3. 查看方案详情（早午晚三餐食物）
```

#### 5. 添加饮食记录
```
1. 切换到"📝 饮食记录"Tab
2. 点击"添加"
3. 输入"燕" → 联想"燕麦"
4. 选择 → 自动填充
5. 保存
```

#### 6. 管理端验证
```
http://localhost:81/diet/ml/management
- 查看68条真实推荐数据
- 查看算法性能对比
```
