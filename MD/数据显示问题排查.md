- 如果有记录 → 重启后端或刷新页面
- 如果无记录 → 添加记录

## 🎯 正确的流程

### 步骤1：确保后端已重启
```batch
# 停止旧进程
taskkill /F /IM java.exe

# 等待3秒
timeout /t 3

# 启动新后端
cd SDR_System-admin
mvn spring-boot:run
```

**等待30秒看到启动成功**

### 步骤2：清除旧的饮食记录（可选）
```sql
-- 如果有旧的记录想清空重新测试
DELETE FROM diet_record WHERE user_id = 1;
```

### 步骤3：添加新记录
```
访问：http://localhost:3000/smart-recommendation
操作：加入菜单（添加食物）
```

### 步骤4：验证数据更新
```

- 连续打卡：1天
- 健康评分：62分
```
