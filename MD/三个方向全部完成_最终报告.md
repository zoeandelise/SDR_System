### ✅ 方向2：算法多样性优化（100%）

#### 创建文件
- ✅ `sql/algorithms/add_diversity_optimization.sql`

#### 核心功能
1. **近期推荐惩罚函数**
   ```sql
   CREATE FUNCTION get_recent_food_penalty(
       p_user_id BIGINT,
       p_food_name VARCHAR(100),
       p_days_back INT
   ) RETURNS DECIMAL(4,2)
   
   逻辑：
   - 7天内推荐0次 → 系数1.0（无惩罚）
   - 7天内推荐1次 → 系数0.7（降权30%）
   - 7天内推荐2次 → 系数0.5（降权50%）
   - 7天内推荐3次+ → 系数0.3（降权70%）
   ```

2. **分类多样性奖励函数**
   ```sql
   CREATE FUNCTION calculate_category_diversity_bonus(
       p_category_name VARCHAR(100)
   ) RETURNS DECIMAL(5,2)
   
   逻辑：
   - 谷物/主食类 → +10分
   - 肉类/蛋类/豆类 → +8分
   - 蔬菜类 → +6分
   - 水果类 → +5分
   - 其他类 → +3分
   ```

3. **多样化推荐存储过程**
   ```sql
   CREATE PROCEDURE generate_diverse_recommendation(
       p_user_id, p_meal_type, p_recommendation_count
   )
   
   逻辑：
   - 基础营养匹配分（0-100）
   - × 近期惩罚系数（0.3-1.0）
   - + 分类奖励分（3-10）
   - + 随机因子（0-10）
   - = 最终评分
   ```
