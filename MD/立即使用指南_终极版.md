## ⚡ 3步快速启动

### 第1步：启动后端（必须）

```batch
cd SDR_System-admin
mvn spring-boot:run
```

**或使用脚本**：
```batch
start_backend.bat
```

**等待**：30秒看到 `Started RuoYiApplication`

---

### 第2步：启动用户端（必须）

```batch
cd sdr-user-frontend
npm start
```

**自动打开**：http://localhost:3000/

**登录账号**：
```
用户名：admin
密码：admin123
```

---

### 第3步：体验AI智能推荐

**操作流程**：
```
1. 登录后，点击首页顶部"立即体验"按钮
   或点击紫色"AI智能推荐"卡片

2. 进入智能推荐页面，点击"🍱 午餐"

3. 查看10种AI推荐食物

4. 点击喜欢的食物的"➕ 加入菜单"按钮

5. 看到Toast提示"✅ 已添加到今日菜单"

6. 添加2-3个食物后，点击底部"查看今日菜单 →"

7. 跳转到饮食记录页面，查看刚添加的食物
```
