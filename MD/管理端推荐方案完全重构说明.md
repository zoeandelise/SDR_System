## 🎯 设计理念


```
用户端生成方案 →
  保存到diet_recommendation表 →
    管理端自动显示 ✓

字段映射：
- user_id → 显示用户名
- meal_type='9' → 显示"🤖 全天方案"
- algorithm_type → 显示"ML智能推荐-全天方案"
- recommended_foods → 显示完整食物列表
- is_accepted='1' → 显示"✓ 已执行"
```

## ✅ 页面功能

### 1. 统计卡片（4个）
```
总方案数：diet_recommendation表记录总数
推荐用户数：去重用户ID
已执行：is_accepted='1'的数量
待执行：is_accepted!='1'的数量
```

### 2. 搜索功能
```
用户搜索：输入用户名或ID
日期范围：查询某个时间段的方案
执行状态：已执行/待执行
```

### 3. 数据表格
```
列：
- 序号
- 推荐用户（蓝色标签）
- 生成日期
- 方案类型（🤖 全天方案，黄色）
- 推荐食物（完整内容）
- 执行状态（✓已执行/⏱待执行）
- 操作（详情/删除）
```

### 4. 详情对话框
```
点击"详情"显示：
- 推荐用户
- 生成日期
- 方案类型
- 算法类型
- 执行状态
- 推荐食物详情（大文本框）
```

## 📊 数据流

### 用户端 → 管理端
```
1. 用户端：点击"一键生成全天方案"
2. 后端：调用generateDailyPlan API
3. 数据库：插入diet_recommendation表
   - meal_type='9'
   - algorithm_type='ML智能推荐-全天方案'
   - recommended_foods='早餐: xxx, 午餐: xxx, 晚餐: xxx'
4. 管理端：刷新页面
5. 显示：新增的方案记录

完全同步！✓
```
