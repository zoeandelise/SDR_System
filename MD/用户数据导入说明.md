# 真实用户数据导入说明

## 📊 数据概况
本SQL脚本将为系统生成**30个真实用户**及其完整数据：

- ✅ 30个用户基本信息（user_id: 101-130）
- ✅ 30份用户健康档案
- ✅ 30份用户饮食偏好
- ✅ 最近7天的饮食记录（每用户3-4条/天）
- ✅ 智能推荐记录

**统一登录密码**: `admin123`

## 🔧 导入方法

### 方法一：MySQL Workbench（推荐）

1. 打开 **MySQL Workbench**
2. 连接到数据库 `ry-vue`
3. 点击菜单 **File** → **Open SQL Script**
4. 选择文件: `E:\study\毕设\SDR_System\sql\generate_real_users.sql`
5. 点击 ⚡**Execute** 按钮（或按 `Ctrl+Shift+Enter`）
6. 等待执行完成，查看底部输出验证结果

### 方法二：Navicat

1. 打开 **Navicat**
2. 连接到 `ry-vue` 数据库
3. 点击菜单 **文件** → **运行SQL文件**
4. 选择文件: `sql\generate_real_users.sql`
5. 选择数据库: `ry-vue`
6. 点击 **开始** 执行

### 方法三：命令行（如果MySQL配置支持）

```batch
cd /d E:\study\毕设\SDR_System
mysql -h localhost -u root -p --ssl-mode=DISABLED ry-vue < sql\generate_real_users.sql
```

然后输入密码: `root`

## 📋 数据验证

导入完成后，执行以下SQL验证数据：

```sql
-- 查看用户总数
SELECT COUNT(*) as user_count FROM sys_user WHERE user_id >= 101;
-- 预期结果: 30

-- 查看健康信息数
SELECT COUNT(*) as health_count FROM sys_user_health WHERE user_id >= 101;
-- 预期结果: 30

-- 查看饮食记录数
SELECT COUNT(*) as record_count FROM diet_record WHERE user_id >= 101;
-- 预期结果: 100+

-- 查看推荐记录数
SELECT COUNT(*) as recommendation_count FROM diet_recommendation WHERE user_id >= 101;
-- 预期结果: 30

-- 查看最近7天活跃用户
SELECT COUNT(DISTINCT user_id) as active_users 
FROM diet_record 
WHERE user_id >= 101 
AND record_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY);
-- 预期结果: 30
```
