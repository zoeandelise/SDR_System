# 假数据清除说明

**问题**：首页显示1847卡路里等假数据  
**原因**：后端createDefaultNutrition返回固定值  
**状态**：✅ 已修复

---

## 🔍 问题分析

### 假数据来源
```java
// UserDietApiController.java
private DietRecord createDefaultNutrition() {
    nutrition.setTotalCalories(new BigDecimal("1847")); // 假数据
    nutrition.setTotalProtein(new BigDecimal("67"));
    nutrition.setTotalFat(new BigDecimal("45"));
    nutrition.setTotalCarbohydrate(new BigDecimal("231"));
}
```

### 问题
```
每次没有记录时，返回固定的1847卡路里
用户看到的不是真实数据
```

---

## ✅ 修复方案

### 修复后
```java
// 如果没有记录，返回0值
todayNutrition = new DietRecord();
todayNutrition.setTotalCalories(new BigDecimal("0"));
todayNutrition.setTotalProtein(new BigDecimal("0"));
todayNutrition.setTotalFat(new BigDecimal("0"));
todayNutrition.setTotalCarbohydrate(new BigDecimal("0"));
```

### 删除
```java
// 完全删除createDefaultNutrition方法
// 删除createDefaultTodayRecords方法
// 确保100%真实数据
```
