# 路由冲突修复说明

**问题**：Ambiguous mapping - 路由冲突  
**原因**：两个Controller映射到同一个URL  
**解决**：删除旧的DietAdminController  
**状态**：✅ 已修复

---

## 🔍 错误分析

### 冲突的映射
```
URL: GET /diet/admin/users

冲突Controller：
1. DietAdminController#getUserList（旧的，diet模块）
2. AdminUsersController#getAllUsersOverview（新的，admin模块）

Spring无法决定使用哪个，启动失败
```

---

## ✅ 解决方案

### 删除旧Controller
```
删除：SDR_System-diet/src/main/java/.../DietAdminController.java
保留：SDR_System-admin/src/main/java/.../AdminUsersController.java
```

### 原因
```
DietAdminController是旧的、可能未完成的代码
AdminUsersController是新创建的、功能完整的代码
```
