## ✅ 数据验证SQL

在数据库工具中验证数据：

```sql
-- 查看所有测试用户
SELECT user_id, user_name, nick_name 
FROM sys_user 
WHERE user_id >= 101 
ORDER BY user_id;

-- 查看今天的饮食记录
SELECT COUNT(*) as today_records, COUNT(DISTINCT user_id) as active_users
FROM diet_record 
WHERE record_date = CURDATE();

-- 查看用户统计（模拟接口返回）
SELECT 
    u.user_id,
    u.nick_name,
    COUNT(dr.record_id) as record_count,
    ROUND(AVG(dr.total_calories), 2) as avg_calories
FROM sys_user u
LEFT JOIN diet_record dr ON u.user_id = dr.user_id
WHERE u.user_id >= 101
GROUP BY u.user_id, u.nick_name
ORDER BY u.user_id
LIMIT 10;
```
