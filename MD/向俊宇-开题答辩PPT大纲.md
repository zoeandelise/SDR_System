## 第13页：核心算法（1）- 规则引擎

### 6大健康约束规则引擎

**规则1：高血压约束**
```sql
IF diseases LIKE '%高血压%' THEN
    -- 高钠惩罚
    UPDATE temp_recommendations
    SET health_score = health_score - 50
    WHERE sodium_per_100g > 200;
    
    -- 低钠奖励
    UPDATE temp_recommendations
    SET health_score = health_score + 20,
        recommendation_reason = CONCAT(reason, '✓低钠适合高血压;')
    WHERE sodium_per_100g <= 100;
END IF;
```

**规则2：糖尿病约束**
```sql
IF diseases LIKE '%糖尿病%' THEN
    -- 高GI惩罚
    UPDATE temp_recommendations
    SET health_score = health_score - 40
    WHERE gi_value > 70;
    
    -- 低GI奖励
    UPDATE temp_recommendations
    SET health_score = health_score + 25,
        recommendation_reason = CONCAT(reason, '✓低GI适合糖尿病;')
    WHERE gi_value <= 55;
END IF;
```

## 第15页：核心算法（3）- 营养匹配

### 营养需求动态计算

**基础代谢率（BMR）计算**：
```
男性：BMR = 88.362 + (13.397 × 体重kg) + (4.799 × 身高cm) - (5.677 × 年龄)
女性：BMR = 447.593 + (9.247 × 体重kg) + (3.098 × 身高cm) - (4.330 × 年龄)
```

**每日总热量需求（TDEE）**：
```
TDEE = BMR × 活动系数 × 健康目标系数

活动系数：
- 久坐：1.2
- 轻度活动：1.375
- 中度活动：1.55
- 高强度活动：1.725

健康目标系数：
- 减脂：0.85（制造热量缺口）
- 增肌：1.15（提供热量盈余）
- 保持：1.00（维持平衡）
```

**蛋白质需求**：
```
减脂：体重(kg) × 1.2g
增肌：体重(kg) × 2.0g
保持：体重(kg) × 1.0g
```

## 第16页：核心算法（4）- 评分函数

### 综合评分函数设计

**总评分公式**：
```
Total_Score = Health_Score + Nutrition_Score + Preference_Score + Diversity_Factor

其中：
Health_Score：健康约束评分（0-100分）
Nutrition_Score：营养匹配评分（0-100分）
Preference_Score：用户偏好评分（0-50分）
Diversity_Factor：多样性因子（RAND() × 30）
```

**营养匹配评分计算**：
```
Nutrition_Score = 100 - |目标热量 - 食物热量| / 目标热量 × 50
                        - |目标蛋白质 - 食物蛋白质| / 目标蛋白质 × 30
```

**最终推荐**：
```sql
SELECT * FROM temp_recommendations
WHERE health_score > 0
ORDER BY total_score DESC, RAND()
LIMIT N;
```

## 第17页：算法流程图

### 完整推荐流程

```
开始
  ↓
读取用户健康信息
├─ 性别、年龄、身高、体重
├─ 疾病史、过敏源
├─ 饮食偏好、健康目标
  ↓
计算营养需求
├─ BMR计算
├─ TDEE = BMR × 活动系数 × 目标系数
└─ 蛋白质 = 体重 × 蛋白质系数
  ↓
查询所有符合条件的食物
└─ 初始评分100分
  ↓
应用健康约束规则（6大规则）
├─ 硬约束：过敏源直接排除（DELETE）
└─ 软约束：疾病限制调整评分（UPDATE）
  ↓
计算营养匹配度
└─ 根据热量和蛋白质匹配度打分
  ↓
添加用户偏好分
└─ 根据历史喜好调整
  ↓
添加多样性因子
└─ RAND() × 30，避免重复
  ↓
排序筛选Top N
└─ ORDER BY score DESC, RAND()
  ↓
生成推荐理由
└─ 拼接所有评分理由
  ↓
返回推荐结果
  ↓
结束
```
