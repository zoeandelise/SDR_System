## 🔧 问题2：训练进度显示错误

### 根因分析

日志显示：
```
10:29:03.642 DEBUG - selectActiveTrainings - <==      Total: 1
```

说明有1条训练状态没有正确更新为completed。

### 修复SQL

```sql
-- 检查异常状态的训练记录
SELECT 
    training_id,
    model_type,
    training_status,
    progress,
    start_time,
    end_time,
    TIMESTAMPDIFF(SECOND, start_time, NOW()) AS elapsed_seconds
FROM ml_training_history
WHERE training_status IN ('pending', 'training')
  AND (end_time IS NOT NULL OR progress = 100);
  
-- 修复：将已完成的训练标记为completed
UPDATE ml_training_history
SET training_status = 'completed',
    progress = 100,
    end_time = COALESCE(end_time, NOW())
WHERE training_status IN ('pending', 'training')
  AND (progress >= 100 OR TIMESTAMPDIFF(SECOND, start_time, NOW()) > 300);
```
