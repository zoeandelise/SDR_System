## 摘要

随着我国居民超重肥胖率超过50%、慢性病患病率持续上升，不合理的膳食结构已成为影响国民健康的重要因素。传统的营养咨询方式因专业人员不足和成本较高而难以满足大规模人群的需求。本文设计并实现了一个基于协同过滤算法的个性化饮食推荐系统，旨在通过信息技术手段为用户提供科学、便捷的饮食管理服务。

系统采用前后端分离的微服务架构，后端基于Spring Boot框架和MyBatis持久层框架开发，推荐算法模块使用Python和FastAPI独立部署，管理端前端采用Vue.js和Element UI构建，用户端前端采用React和TypeScript开发，数据库使用MySQL存储。

系统的核心推荐引擎实现了基于矩阵分解的协同过滤算法，通过分析用户之间的相似性为用户推荐个性化的食物。同时实现了基于内容的推荐算法，通过营养特征、文本特征和分类特征的融合计算食物相似度。两种算法以加权方式融合构建混合推荐模型（协同过滤60% + 内容推荐40%）。为确保推荐结果的健康性，系统将营养学约束规则融入推荐流程，针对高血压、糖尿病、痛风等常见慢性病制定了相应的营养限制规则。

系统实现了用户管理、健康档案管理、食物库管理（55种食物，14项营养指标）、饮食记录、智能推荐和营养统计分析六大功能模块。针对新用户的冷启动问题，系统设计了基于健康档案的初始推荐策略和三级降级推荐机制。经全面测试，系统功能完善、性能稳定，推荐结果满足个性化和健康性的双重要求。

**关键词：** 协同过滤算法；个性化推荐；饮食推荐系统；矩阵分解；营养约束

## Abstract

With China's adult overweight and obesity rate exceeding 50% and the prevalence of chronic diseases continuing to rise, unreasonable dietary structure has become an important factor affecting national health. Traditional nutritional consultation methods are unable to meet the needs of large-scale populations due to insufficient professionals and high costs. This paper designs and implements a personalized dietary recommendation system based on collaborative filtering algorithm, aiming to provide users with scientific and convenient dietary management services through information technology.

The system adopts a microservice architecture with front-end and back-end separation. The back-end is developed based on Spring Boot framework and MyBatis persistence layer framework, the recommendation algorithm module is independently deployed using Python and FastAPI, the management front-end is built with Vue.js and Element UI, the user front-end is developed with React and TypeScript, and MySQL is used as the database.

The core recommendation engine implements a collaborative filtering algorithm based on matrix factorization, which recommends personalized food to users by analyzing similarities between users. A content-based recommendation algorithm is also implemented, calculating food similarity through the fusion of nutritional features, text features and classification features. The two algorithms are combined in a weighted manner to build a hybrid recommendation model (collaborative filtering 60% + content-based 40%). To ensure the healthfulness of recommendation results, the system integrates nutritional constraint rules into the recommendation process, with corresponding nutritional restriction rules for common chronic diseases such as hypertension, diabetes, and gout.

The system implements six major functional modules: user management, health profile management, food database management (55 foods with 14 nutritional indicators), diet recording, intelligent recommendation, and nutritional statistical analysis. To address the cold start problem for new users, the system designs an initial recommendation strategy based on health profiles and a three-level degradation recommendation mechanism. Through comprehensive testing, the system demonstrates complete functionality, stable performance, and recommendation results that meet the dual requirements of personalization and healthfulness.

**Keywords:** Collaborative Filtering Algorithm; Personalized Recommendation; Dietary Recommendation System; Matrix Factorization; Nutritional Constraints
