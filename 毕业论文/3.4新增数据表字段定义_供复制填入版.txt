以下是论文 3.4 数据库设计章节需要补充的5张新增数据表的字段定义。
字段信息来源于项目实际数据库结构（通过建表SQL和控制器SQL语句提取）。
格式与您提供的"饮食打卡表"示例完全一致，可直接复制粘贴到Word中。

==============================================================================
(1) 社区动态实体
==============================================================================

社区动态实体包括动态ID、用户ID、正文内容、图片链接、点赞数、评论数、
删除标记、创建时间、更新时间等属性，如图x.x所示。

图x.x 社区动态实体属性图

社区动态表存储用户发布的饮食分享动态，以动态ID作为主键唯一标识每条
动态记录。该表的字段定义如表x.x所示。

表x.x 社区动态表（diet_post）

字段名称          数据类型          主键    是否空    说明
post_id           bigint(20)        Y       N        动态ID（主键，自增）
user_id           bigint(20)        N       N        发布用户ID（外键）
content           text              N       N        动态正文内容
image_urls        varchar(1000)     N       Y        图片链接（多图以逗号分隔）
like_count        int(11)           N       Y        点赞数（默认为0）
comment_count     int(11)           N       Y        评论数（默认为0）
del_flag          char(1)           N       Y        删除标记（0正常 1已删除）
create_time       datetime          N       Y        创建时间
update_time       datetime          N       Y        更新时间


==============================================================================
(2) 社区点赞实体
==============================================================================

社区点赞实体包括点赞ID、动态ID、用户ID、创建时间等属性，如图x.x所示。

图x.x 社区点赞实体属性图

社区点赞关联表记录用户与动态之间的点赞关系。动态ID与用户ID的组合
唯一索引确保同一用户对同一动态只能有一条点赞记录。该表的字段定义如
表x.x所示。

表x.x 社区点赞表（diet_post_like）

字段名称          数据类型          主键    是否空    说明
like_id           bigint(20)        Y       N        点赞ID（主键，自增）
post_id           bigint(20)        N       N        动态ID（外键）
user_id           bigint(20)        N       N        点赞用户ID（外键）
create_time       datetime          N       Y        点赞时间


==============================================================================
(3) 社区评论实体
==============================================================================

社区评论实体包括评论ID、动态ID、用户ID、评论内容、创建时间等属性，
如图x.x所示。

图x.x 社区评论实体属性图

社区评论表存储用户对社区动态的评论内容。该表的字段定义如表x.x所示。

表x.x 社区评论表（diet_post_comment）

字段名称          数据类型          主键    是否空    说明
comment_id        bigint(20)        Y       N        评论ID（主键，自增）
post_id           bigint(20)        N       N        所属动态ID（外键）
user_id           bigint(20)        N       N        评论用户ID（外键）
content           varchar(500)      N       N        评论内容
create_time       datetime          N       Y        评论时间


==============================================================================
(4) 科普资讯实体
==============================================================================

科普资讯实体包括文章ID、标题、作者、封面图、正文内容、浏览次数、
发布状态、创建时间等属性，如图x.x所示。

图x.x 科普资讯实体属性图

科普资讯表存储管理员发布的营养科普文章，以文章ID作为主键唯一标识
每篇文章。该表的字段定义如表x.x所示。

表x.x 科普资讯表（diet_article）

字段名称          数据类型          主键    是否空    说明
article_id        bigint(20)        Y       N        文章ID（主键，自增）
title             varchar(200)      N       N        文章标题
author            varchar(64)       N       Y        作者名称
cover_image       varchar(500)      N       Y        封面图片URL
content           text              N       N        文章正文内容
view_count        int(11)           N       Y        浏览次数（默认为0）
status            char(1)           N       Y        发布状态（0已发布 1草稿）
create_time       datetime          N       Y        创建时间


==============================================================================
(5) 收藏记录实体
==============================================================================

收藏记录实体包括收藏ID、用户ID、收藏类型、目标ID、目标名称、目标描述、
目标图片、创建者、创建时间、更新时间、备注等属性，如图x.x所示。

图x.x 收藏记录实体属性图

收藏记录表存储用户的收藏信息，支持对食物、食谱、推荐方案等不同对象
的收藏操作。用户ID、收藏类型与目标ID的组合唯一索引确保同一用户不会
对同一对象重复收藏。该表的字段定义如表x.x所示。

表x.x 收藏记录表（diet_favorites）

字段名称          数据类型          主键    是否空    说明
favorite_id       bigint(20)        Y       N        收藏ID（主键，自增）
user_id           bigint(20)        N       N        用户ID（外键）
favorite_type     varchar(20)       N       N        收藏类型（food/recipe/recommendation）
target_id         bigint(20)        N       N        目标ID（食物ID/食谱ID/推荐方案ID）
target_name       varchar(200)      N       N        目标名称
target_description text             N       Y        目标描述
target_image      varchar(500)      N       Y        目标图片URL
create_time       datetime          N       N        创建时间
create_by         varchar(64)       N       Y        创建者
update_time       datetime          N       Y        更新时间
update_by         varchar(64)       N       Y        更新者
remark            varchar(500)      N       Y        备注
